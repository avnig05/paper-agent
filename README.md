# Paper Agent

An AI-powered research assistant that helps users understand
machine learning research papers.

## Planned Features
- PDF upload and text extraction
- AI-powered paper summaries
- Chat with research papers
- Interactive knowledge graphs
- Equation explanations
- AI-generated quizzes and flashcards

## Tech Stack
- Python
- FastAPI
- Next.js
- React
- ChromaDB
- LLM APIs
